# Комодский варан — лендинг автосервиса

Одностраничный сайт автосервиса в Барановичах. Сделан на чистом HTML, CSS и JavaScript, без сборщиков и фреймворков.

## Структура

```
index.html          — разметка сайта и SVG-спрайт иконок
style.css           — вся стилизация и адаптивность
script.js           — меню, анимации появления, форма, предвыбор услуги
logo.svg            — логотип (буква К + гаечный ключ)
parse_reviews.py    — парсер отзывов с Яндекс.Карт
reviews.json        — 6 последних отзывов + рейтинг организации
1.jpg               — фон первого экрана (Hero)
2.jpg               — фото «Руки мастера» в блоке «Почему мы»
3.jpg               — фото в карточке услуги «Кузовной ремонт»
4.jpg               — портрет Виталия Степановича в блоке «Контакты»
privacy.html         — политика в отношении обработки персональных данных
preview-desktop.png  — превью первого экрана для десктопа
preview-mobile.png   — превью первого экрана для смартфона
preview-map.png      — превью интерактивной Яндекс.Карты
preview-transport.png — превью блока «Транспорт»
preview-prices.png   — превью услуг с ценами
```

## Запуск

```bash
cd komodskiy_varan_site
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть: <http://127.0.0.1:8000/>

Сайт можно открыть и напрямую через `index.html`, но для проверки в условиях, близких к хостингу, запустите локальный сервер.

## Отзывы

`parse_reviews.py` делает один запрос к публичной странице отзывов, извлекает имя, оценку, дату и текст, сортирует по дате и сохраняет 6 последних отзывов в `reviews.json`.

```bash
pip install requests
python3 parse_reviews.py
```

Данные на сайте размещены статически (в `index.html`) и соответствуют `reviews.json` на момент сборки. При обновлении отзывов нужно обновить карточки в блоке «Отзывы» (или подключить рендер из JSON). Разметка Яндекс.Карт может меняться, поэтому при сбое парсера стоит проверить селекторы. Соблюдайте условия использования Яндекс.Карт.

## Форма

Заявка отправляется напрямую в Telegram Bot API (`sendMessage`) через `fetch`:

- токен и `chat_id` заданы константами в `script.js`;
- сообщение содержит имя, телефон, автомобиль, услугу и комментарий;
- `disable_notification: false` — уведомление приходит со звуком;
- на время отправки кнопка блокируется и показывает «Отправка...»;
- при успехе показывается благодарность, при ошибке — сообщение с телефоном;
- отправка возможна только после отметки обязательного согласия на обработку персональных данных со ссылкой на `privacy.html`.

**Важно:** получатель должен сначала запустить бота [@komod_varan_bot](https://t.me/komod_varan_bot) и нажать «Запустить», иначе Telegram отвечает `Bad Request: chat not found`. Токен находится в клиентском коде и виден посетителям сайта — для публичного проекта отправку лучше проксировать через сервер/CRM.

## Ассеты и права

- Логотип и вся графика интерфейса — оригинальные SVG.
- Фотографии `1.jpg`–`4.jpg` предоставлены заказчиком и используются как контент сайта.
- Карта: интерактивный виджет Яндекс.Карт (iframe). Для отображения карты требуется доступ в интернет; условия использования — на стороне Яндекс.Карт.
- Юридические данные (ООО, УНП, адрес, телефоны) взяты из брифа.
- В политике указан email `info@komodskiyvaran.by` как временный: в брифе фактический адрес электронной почты не предоставлен. Замените его на реальный email оператора перед публикацией. Политика носит базовый характер — рекомендуется проверка юристом.
